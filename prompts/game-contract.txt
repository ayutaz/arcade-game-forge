Common game state:
- phase 0=title, 1=playing, 2=won, 3=lost; score=0, elapsed=0 at init/reset.
- Player starts at spec.start; coins, RNG=spec.seed, timer accumulator and hazard reset completely.
- debug_value returns (phase << 16) | score. debug_x/debug_y return player tile coordinates.
- debug_elapsed returns elapsed milliseconds. No extra exports.
- First, if pressed & BACK, return 1 before any other work.
- Next, if pressed & RESET, reset to title and draw. Ignore all other inputs/dt on that frame.
- At title, START changes to playing. That frame does not consume dt or move. Other keys ignored.
- At won/lost, all keys except RESET/BACK are ignored and elapsed is frozen.
- When playing: elapsed=min(duration_ms,elapsed+dt). At the deadline lose immediately, without movement.
- Otherwise move at most one tile, in priority RIGHT, LEFT, DOWN, UP. Reject outside/wall moves.
- For dodge, ignore the chosen vertical movement (do not fall through to another input).
- After movement apply the genre rules below. Always draw the resulting state, except on BACK.

Genre maze:
- Reach the goal to set score=1 and phase=won. No coins/hazards.

Genre collect:
- Touching an uncollected coin removes it and increments score once.
- Win when all coins are collected. No goal/hazards.

Genre dodge:
- Player stays in the bottom row. One falling hazard at a time, initially absent.
- After movement, accumulator += dt. While accumulator>=step_ms and phase==playing:
  1. accumulator -= step_ms.
  2. If a hazard exists, increment its y. If y>=height, score++ and remove the hazard.
     If score==target, win and break immediately, without spawning another hazard.
  3. If no hazard exists, RNG=(1664525*RNG+1013904223) modulo 2^32;
     spawn at x=RNG%width, y=0. The initial spawn also follows this rule.
  4. If the hazard overlaps the player, lose. No extra movement between timer steps.
- elapsed includes the entire frame dt, even when the timer loop reaches won/lost partway through it.
